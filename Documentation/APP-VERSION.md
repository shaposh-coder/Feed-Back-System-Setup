# App version

**Store Feedback System** — version **1.0.0** (released 2026-10-28)

See [CHANGELOG.md](./CHANGELOG.md) for the full history.

## This release includes

- Public multi-step customer feedback form for store visits
- Admin dashboard with chart insights across key survey questions
- Feedback entries browsing with status filters and detail views
- Brand settings (store name, logo, favicon) and admin profile controls
- Offline Demo Mode for portfolio review without a live backend
