# Getting started

**Version:** 1.0.0

Store Feedback System helps retail teams collect store-visit feedback and review trends in an admin dashboard.

## Try Demo Mode

1. Follow the run steps in `demo-mode/README.md`.
2. Open the Demo Mode app in your browser.
3. On **Sign in**, choose a demo account card (Admin, Store Manager, or Viewer).
4. Explore the [Dashboard](./03-dashboard.md), [entries](./05-entries.md), [brand settings](./07-brand-settings.md), and [profile](./08-profile.md).
5. Optionally open `/` to submit a sample customer response, then refresh the admin views.

## Production app (maintainers)

The production app at the repository root uses a live database and authenticated admin users. See the root `README.md` for install and environment setup.
